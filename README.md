TF2C plugin and custom item schema that attempts to recreate TF2 as it existed in mid-2012.

# Mem Patches
- Heavies are able to eat their own thrown Sandviches
- The Sandman stuns enemies
- Demo swords don't have a deploy/holster penalty
- The Ullapool Caber has it's original base damage and lack of damage falloff

# Dependencies
[Source Scramble](https://github.com/nosoop/SMExt-SourceScramble/)
